# 🎸 Guitar Store Management System (C++)

Welcome to the **Guitar Store Management System** — a C++ OOP project designed to manage and display a virtual inventory of guitars using key object-oriented programming features.

## 📚 Features

- 🧠 **Polymorphism** via virtual base class `Guitars`
- 🎯 **Inheritance** for specific types: `ElectricGuitars`, `AcousticGuitars`, `ClassicalGuitars`
- 🧰 **Templates** for a generic `Store<T>` inventory class
- 🧼 **Destructor** and **Copy Constructor** for deep memory management
- 🤝 **Friend Functions** to calculate total store value
- 🖨️ Terminal output using **ANSI bold formatting**
